        LIVE-Zielrennen

        So funktioniert das Rennen

        Das LIVE-Zielrennen findet unter allen aktiven Mitarbeitern, Vertriebsmitarbeitern, Admins und Superadmins statt.

        • Vertrieb und Mitarbeiter: Eine echte LIVE-Beantragung zählt sofort für den Antragsteller.
        • Wird diese Beantragung von Admin oder Superadmin auf LIVE freigegeben, bleibt der Punkt beim ursprünglichen Antragsteller.
        • Wird sie abgelehnt oder auf einen anderen Status zurückgestellt, fällt der Punkt sofort aus dem Rennen.
        • Admins und Superadmins erhalten einen Punkt für jede eigene, direkt auf LIVE gesetzte Schaltung.
        • Die Wertung läuft über den gesamten Zeitraum.
        • Dein Fortschritt wird gegen den Zielwert „Live-Anbieter“ des gewählten Landes berechnet.
        • Du siehst nur deinen eigenen Fortschritt und deinen aktuellen Platz.
